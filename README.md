🎃 ENIGMA

A 2D pixel-art horror game about Halloween night.

Earth, 2055. An asteroid fell, and something came with it. The Enigmas took the world: strong, mysterious creatures that cannot be fought and exist only to be entertained. Every Halloween, kids still go trick-or-treating, because the Enigmas demand it. Many never come home.

You are one of those kids. Knock on the door. An Enigma opens it and says TRICK or TREAT. Survive their games and reach the party at the end of the street.

There is no combat in this game. You survive by playing the minigames.

Features
Original dark Halloween look: grainy film noise, vignette, scanlines, dynamic lighting and fog, all drawn in code.
Demonic pixel logo: blood-red lettering with dripping pixels, and the "I" is a flickering lightbulb that lights up the whole word.
Short story intro that sets up the world.
Boy or girl costume at character select.
7 houses, 7 Enigmas: each appears as a tall hooded figure at the door, then reveals its true form when it says TRICK.
Two Trick minigames
The Maze: you are dragged into a dark house and must find the exit. The Enigma behaves like a Pac-Man ghost: it wanders, stalks, and chases in short bursts, makes mistakes, and loses interest. It is not a perfect tracker.
Find the Doll: find the haunted doll among the others before she blinks three times. Clues: a red ribbon, pale eyes, and a hot/cold light that warms as your cursor gets closer.
Treat minigame: a safe room where a Grandma drops candy into a black battle box and you move a heart to catch it. A different Grandma, with a different name, appears each time. Candy heals you, and golden candy gives a buff for your next Trick.
Buffs: Speed Boost, Slow Enigma, Eagle Eye, and Shield.
The Party finale: walk through the portal into a ballroom full of friendly ghost Enigmas, talk to them, then start the dance for confetti and HAPPY HALLOWEEN!!!!
All audio generated live with the Web Audio API: drone, ambient scares, music box melodies, chase pulse, and a party track. No audio files.
No external assets. Every sprite and sound is generated by code. The only outside request is the pixel font from Google Fonts.

How to play
Walk to the lit house and press Z / Enter to knock.
The Enigma says TRICK or TREAT.
Trick: win the Maze or Doll game to move on. If your HP hits 0 or the doll finds you, you can retry the house.
Treat: catch candy for 20 seconds to heal and earn a buff.
After the 7th house, walk into the portal at the end of the street.
At the party, talk to the ghosts, then press Z / Enter at the DJ stage to start the dance.
Run it locally

No install or build step. It is a single HTML file.

bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPO-NAME.git
cd YOUR-REPO-NAME

Then open index.html in a modern browser (Chrome, Edge, Firefox, or Safari). Sound starts after your first key press, because browsers block autoplay audio.

A keyboard is required. There are no touch controls.

Deploy with GitHub Pages
Push index.html to your repo.
Go to Settings → Pages.
Under Build and deployment, choose Deploy from a branch, then select main and / (root).
Save, and your game goes live at https://YOUR-USERNAME.github.io/YOUR-REPO-NAME/.
Tech
HTML5 Canvas and vanilla JavaScript, all in one file
640×360 internal resolution, scaled up with pixelated rendering
Sprites built from palette-indexed pixel maps
Web Audio API for all music and sound effects
"Press Start 2P" font from Google Fonts, with a monospace fallback
Known limitations
Keyboard only.
Progress is not saved. Refreshing the page starts a new run.
The Maze has no hiding spots yet.
